# ADR 0003: Licence for published data

**Status:** open, decide before the first data release (target: Gate 1, Feb 2027)

## Options

| Option | For | Against |
| --- | --- | --- |
| CC-BY 4.0 | Maximum adoption; simple for researchers and companies | A closed vendor could absorb the registry without giving back |
| ODbL 1.0 | Derived databases must stay open (share-alike) | Some companies avoid share-alike data entirely |
| CC0 | No friction at all | No attribution, no protection |

## Constraints that apply whatever we choose

- Never redistribute CUSIP master data (licensed by CUSIP Global Services). Use the SEC 13F Official List and FIGIs.
- Never redistribute price data. Evidence studies use a bring-your-own-prices adapter.
- Congressional disclosure data is restricted for commercial use under the Ethics in Government Act.
