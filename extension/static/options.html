Ownership Engine · options

The extension asks oe serve on this computer. Start it with scripts\start.ps1, then paste the token from data\serve\token.txt in the repository folder. The token stays in this browser and is only ever sent to 127.0.0.1 or localhost.

What it does, and does not do

  • Looks up a name or ticker you type, select and right-click, or enter after oe in the address bar.
  • Does not read the pages you visit, and sends nothing anywhere except to oe serve on this computer.
  • “Open profile” opens the full web app, signed in for the current run of oe serve.
